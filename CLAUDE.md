# CLAUDE.md

CiviTest is an offline French civic-exam quiz app (Expo SDK 54 / React Native, single app at repo root).

## Commands

- `npm start` — run the app (Expo)
- `npm run lint` — ESLint (`expo lint`)
- `npx tsc --noEmit` — type-check
- Build APK: `npx expo prebuild -p android --clean && (cd android && ./gradlew assembleRelease)`

## Architecture

- **Routing:** Expo Router, file-based, under `src/app/`.
- **Styling:** NativeWind (`className`); design tokens in `src/theme/`.
- **State/data:** TanStack Store + Query; quiz history in `expo-sqlite` (`src/utils/storage.ts`).
- **Questions:** bundled JSON in `assets/data/`, validated with `zod` (`src/lib/`).
- Import alias: `@/*` → `src/*`.

## Conventions

- **Offline-first:** no accounts, analytics, or tracking, and the quiz experience makes no
  network calls. Keep it that way. The one exception is the optional in-app tip
  (`DonationSheet`), which uses platform billing; do not add any other network use.
- **NativeWind gotcha:** a `style` function prop is dropped, and the `active:` pseudo-class makes a
  child its own touch responder (swallowing the parent's `onPress`). Use a static style object with a
  `pressed` state for press feedback instead.
- `android/` and `ios/` are git-ignored and regenerated by `expo prebuild` — never edit them by hand.
- Distribution is APK via GitHub Releases (no Play Store); CI lives in `.github/workflows/`.
